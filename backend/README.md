# BCIS Subscription Billing and Collection System — Backend API

Fastify REST API server for BCIS Subscription Billing and Collection System.

## Stack
- Fastify 5
- TypeScript strict
- PostgreSQL 17 + Drizzle ORM
- Zod validation
- Pino structured logging
- Vitest testing
- OpenAPI 3.0 specification

## Commands
```bash
pnpm install
pnpm dev
pnpm test
pnpm typecheck
pnpm build
pnpm openapi:generate
```

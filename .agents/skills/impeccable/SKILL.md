# Impeccable Design & Layout Protocol

## Directives
- **Anti-Slop Guard:** Never output generic Inter-only fonts, raw purple-to-blue default gradients, or double-nested rounded cards.
- **State Completeness:** Every interactive UI component must handle 6 core states: default, hover, active/pressed, focus-visible, loading/skeleton, and empty.
- **Normalization:** Ensure consistent token spacing (using an 8pt/4pt grid), explicit z-index layering, and consistent border radii.
- **Design System Grounding:** Maintain a `DESIGN.md` and `PRODUCT.md` file in the project root to store verified color tokens, typography scales, and component specs.

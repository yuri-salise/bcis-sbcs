# BCIS Subscription Billing and Collection System — Desktop Client

Tauri 2.x + React 19 + TypeScript desktop client for BCIS Subscription Billing and Collection System.

## Stack
- Tauri 2.x (Windows desktop shell, strict capability boundaries)
- Vite + React 19
- TypeScript strict
- Tailwind CSS v4 (`Operational Trust` palette)
- TanStack Query + TanStack Table
- Lucide React icons
- Vitest + React Testing Library

## Commands
```bash
pnpm install
pnpm dev
pnpm test
pnpm typecheck
pnpm build
```
